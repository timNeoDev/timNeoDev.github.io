# Радар заказов

Личный инструмент фрилансера. Каждые 3 минуты проверяет новые заказы на FL.ru, находит подходящие по ключевым словам и присылает их в Telegram с кнопками «✅ Откликнулся» и «🙈 Скрыть». В веб-админке видны все заказы, там же меняются ключевые слова и видна статистика.

## Возможности
- Сбор заказов из RSS-ленты FL.ru раз в 3 минуты. Повторно один и тот же заказ не сохраняется.
- Поиск по ключевым словам с начала слова, без учёта регистра и разницы между ё и е: «бот» найдёт «боты», но не «работа».
- Telegram-бот: уведомления о подходящих заказах, кнопки статуса, команды `/keywords`, `/add`, `/del`, `/stats`. Бот отвечает только владельцу.
- Веб-админка с паролем: вкладки «Новые / Откликнулся / Скрытые / Все», управление ключевыми словами, статистика.
- При первом запуске бот не присылает уведомления о заказах, которые уже есть в ленте.

## Стек
Python 3.11+, aiogram 3, aiohttp (веб-админка), SQLite. Всё работает в одном процессе.

## Запуск
```bash
python -m venv venv
venv\Scripts\activate            # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env           # Linux/macOS: cp .env.example .env
python main.py
```
В `.env` укажите `ADMIN_PASSWORD`, без него программа не запустится. Для уведомлений в Telegram нужны ещё `BOT_TOKEN` от [@BotFather](https://t.me/BotFather) и ваш `ADMIN_ID`. Без них работает только веб-админка.

Админка открывается по адресу http://127.0.0.1:8080.

Тесты: `python test_radar.py`

## Структура
```
main.py     — запуск: сбор заказов + бот + веб-сервер
feeds.py    — загрузка RSS и поиск ключевых слов
db.py       — SQLite: заказы и ключевые слова
bot.py      — Telegram-бот
web.py      — веб-админка
config.py   — настройки и список лент
```

## Ограничения
- Публичная RSS-лента есть только у FL.ru. У Хабр Фриланса и Kwork её нет. Новую ленту можно добавить в `FEEDS` в [config.py](config.py).
- Админка по умолчанию доступна только с этого компьютера (`127.0.0.1`). На сервере её нужно открывать через HTTPS (например, nginx и Let's Encrypt), иначе пароль будет передаваться открытым текстом.
