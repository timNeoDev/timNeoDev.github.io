# Радар заказов

Рабочее место фрилансера. Радар собирает свежие заказы с Kwork, присылает подходящие в Telegram и ведёт все ваши проекты в одной веб-админке: отклики, клиенты, сроки, оплаты, доход и аналитику рынка.

## Возможности

**Сбор заказов**
- Kwork, раздел «Разработка и IT»: проверка каждые 3 минуты.
- По каждому заказу: бюджет и допустимый максимум, **просмотры**, **число откликов** (обновляются при каждой проверке), категория, время публикации.
- Умные фильтры: ключевые слова, минус-слова, минимальный бюджет. Слова ищутся с начала слова: «бот» найдёт «боты», но не «работа».
- 🔥 «Горячий» заказ: опубликован меньше часа назад, откликов не больше трёх.

**Telegram-бот** (отвечает только владельцу)
- Уведомление о подходящем заказе с кнопками «✅ Откликнулся», «🙈 Скрыть», «💼 В CRM», «📝 Шаблоны».
- Утром напоминание о дедлайнах, вечером сводка за день.
- Команды: `/keywords`, `/add`, `/del`, `/minus`, `/unminus`, `/budget`, `/projects`, `/stats`, `/digest`.

**Веб-админка** (вход по паролю)
- **Обзор:** найдено сегодня, отклики за неделю, конверсия «отклик → проект», доход за месяц, графики по дням и месяцам, воронка, горячие заказы, ближайшие дедлайны.
- **Заказы:** вкладки по статусам, поиск, фильтр по бюджету и «только горячие».
- **Сделки:** путь от отклика до оплаты (отклик отправлен → в диалоге → на уточнении → на согласовании → можно начинать → в работе → правки клиента → на проверке → сдан → оплачен / отказ). У каждой сделки: клиент, сумма, дедлайн, дата «напомнить клиенту», стоимость отклика и возврат, платежи с предоплатой.
- **Финансы:** предварительный доход, оплаты, ждём оплаты, потенциально, загрузка, закрыто; налог самозанятого.
- **Аналитика:** в диалоге, пора напомнить, конверсия откликов, траты, окупаемость и прибыль по источникам.
- **Клиенты, поиск, шаблоны откликов.**
- **Настройки:** аккаунты бирж, Telegram-каналы и чаты, ключевые и минус-слова, бюджет, цель дохода, налог.

**Telegram-каналы и чаты**
- **Публичные каналы** читаются через веб-версию `t.me/s/<канал>`, без аккаунта и без бота. Сразу подключены @digitaltender, @freelancetaverna, @FreeWorkFeed, @workk_on, @normrabota, @webfrl. Свои каналы добавляются в «Настройки → Telegram-каналы и чаты».
- **Чаты (группы)** читаются от имени вашего аккаунта через официальный API Telegram (Telethon). Заказом считается только сообщение со словами вроде «нужен», «ищу», «бюджет», «заказ», остальное — болтовня. Автор сообщения указывается в описании, чтобы ему можно было сразу написать.
- Бюджет ищется прямо в тексте: «15 000 ₽», «10к», «до 20 тыс. руб».
- Новый канал не рассылает старые посты в Telegram: уведомления начинаются со следующего заказа.
- При изменении ключевых слов, минус-слов или бюджета уже найденные новые заказы перепроверяются.

### Telegram-чаты: как подключить аккаунт
1. Откройте https://my.telegram.org, войдите и перейдите в **API development tools**. Создайте приложение с любым названием и скопируйте `api_id` и `api_hash`.
2. Впишите их в `.env` как `TG_API_ID` и `TG_API_HASH`.
3. Выполните `python tg_login.py`, введите номер телефона и код из Telegram. Появится файл `radar_user.session`: это доступ к вашему аккаунту, никому его не передавайте (в git он не попадёт).
4. Перезапустите радар и добавьте чаты в настройках с типом «Чат».

Радар только **читает** сообщения, раз в 3 минуты, и ничего не отправляет от вашего имени. Telegram разрешает такие сторонние клиенты, но слишком частые запросы могут привести к временному ограничению аккаунта.

## Стек
Python 3.11+, aiogram 3, aiohttp (веб-сервер), Jinja2 (шаблоны с автоэкранированием), SQLite. Графики сделаны на CSS, без JS-библиотек. Всё работает в одном процессе.

## Запуск
```bash
python -m venv venv
venv\Scripts\activate            # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env           # Linux/macOS: cp .env.example .env
python main.py
```
- `ADMIN_PASSWORD` — пароль от админки. Обязательный параметр, без него радар не запустится.
- `BOT_TOKEN` (от [@BotFather](https://t.me/BotFather)) и `ADMIN_ID` (ваш Telegram ID) нужны для уведомлений. Без них работает только админка.

Админка: http://127.0.0.1:8080 · Тесты: `python test_radar.py`

## Структура
```
main.py      — запуск: сбор заказов (Kwork, Telegram), бот, веб-сервер, ежедневные сообщения
tg_user.py   — чтение Telegram-чатов через ваш аккаунт (Telethon)
tg_login.py  — однократный вход в аккаунт для чтения чатов
sources.py   — Kwork и публичные Telegram-каналы: загрузка и разбор; фильтры; «горячие» заказы
db.py        — SQLite: заказы, фильтры, проекты, платежи, шаблоны, аналитика
bot.py       — Telegram-бот
web.py       — веб-админка (маршруты)
templates/   — страницы админки (Jinja2)
static/      — стили и скрипт копирования
```

## Ограничения
- Kwork не даёт публичного API, поэтому радар читает данные со страницы заказов. Если Kwork поменяет вёрстку, сбор остановится: в админке появится ошибка, а тест разбора нужно будет обновить.
- Profi.ru показывает заказы только специалисту, который вошёл в аккаунт. Его подключение — следующий этап.
- По умолчанию админка доступна только с этого компьютера (`127.0.0.1`). На сервере её нужно открывать через HTTPS (nginx и Let's Encrypt), иначе пароль будет передаваться открытым текстом.
