# ИИ-консультант кофейни на Claude

Telegram-бот, который отвечает гостям кофейни как живой бариста: знает меню, цены и условия, советует напитки под вкус и принимает заявки на бронь столика. Работает на [Claude API](https://platform.claude.com) от Anthropic.

## Возможности
- **Ответы ИИ в реальном времени**: текст печатается в сообщении по мере генерации.
- **Только факты из базы знаний** ([knowledge.md](knowledge.md)). Если ответа нет, бот честно говорит об этом и даёт телефон.
- **Память диалога**: бот понимает уточнения вроде «а без лактозы?» и «а сколько стоит?».
- **Бронирование**: если гость хочет забронировать столик, ИИ сам показывает кнопку. Бот собирает имя, телефон и время и присылает заявку администратору.
- **Контроль расходов**: дневной лимит сообщений на пользователя и кэширование промпта. Команда `/stats` показывает расход в долларах.
- **Устойчивость**: при ошибке API гость получает вежливое сообщение. Если модель отказывается отвечать, запрос автоматически повторяется на запасной модели.

**Демо-режим**: если `ANTHROPIC_API_KEY` не задан, бот отвечает по правилам из [demo.py](demo.py). Он узнаёт тему вопроса и позиции меню по ключевым словам и тоже выводит ответ постепенно. Так бота можно показать без оплаты API. Чтобы включить настоящий Claude, добавьте ключ в `.env` и перезапустите бота.

Команды администратора: `/stats` — статистика и расход, `/bookings` — последние заявки.

## Стек
Python 3.11+, aiogram 3, Anthropic SDK (модель `claude-opus-5-5`, потоковый ответ, кэширование промпта), SQLite.

## Запуск
```bash
python -m venv venv
venv\Scripts\activate          # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env         # Linux/macOS: cp .env.example .env
```
Заполните `.env`:
1. `BOT_TOKEN` — токен нового бота от [@BotFather](https://t.me/BotFather).
2. `ADMIN_ID` — ваш Telegram ID от [@userinfobot](https://t.me/userinfobot).
3. `ANTHROPIC_API_KEY` — ключ из [Claude Console](https://platform.claude.com/settings/keys). API оплачивается отдельно от подписки Claude.

Запустите: `python bot.py`

## Как адаптировать под другой бизнес
1. Замените [knowledge.md](knowledge.md) на информацию о своём бизнесе.
2. Поменяйте название, адрес и телефон в [config.py](config.py), а меню — в `MENU_TEXT` в [bot.py](bot.py).
3. Если нужно, поправьте тон общения в `SYSTEM_PROMPT` в [ai.py](ai.py).

## Структура
```
bot.py        — обработчики Telegram, стриминг ответа, бронирование
ai.py         — запрос к Claude, системный промпт, подсчёт стоимости
demo.py       — демо-режим без ключа API
storage.py    — история диалогов, лимиты, SQLite (заявки и статистика)
knowledge.md  — база знаний кофейни
config.py     — настройки
```

## Сколько стоит работа
Один ответ стоит примерно $0.01–0.02. Цены Claude Opus 5.5: $4 за 1 млн входящих токенов и $20 за 1 млн исходящих. Повторное чтение базы знаний из кэша стоит в 20 раз дешевле обычного. При лимите 30 сообщений в день на человека расходы предсказуемы.
